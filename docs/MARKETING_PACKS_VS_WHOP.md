# Marketing lock — Packs IA vs Whop (2026-10-31)

Aligné `docs/COMMERCIAL_MODEL.md` · GitBook revue nº 24.

## Messages autorisés

### Packs IA (Pulse / Yield / Sentinel)
- Achat **unique** (crypto ou carte)
- NFT MultiversX **édition limitée** (Genesis)
- Droits d’accès **durables** (pas d’expiration annuelle)
- Performance affichée = **paper / simulation** jusqu’à GO merchant
- Badge : **PAPER · Model C**

### Whop xArtists
- **Abonnement mensuel**
- Accès services / TCA du plan Whop
- **Ne délivre pas** de NFT Genesis pack
- Section UI et copy **séparées**

## Interdits (copy & ads)

- Promesse de rendement live / APY garanti
- « Fonds gérés » / mandat de gestion
- Confusion abonnement Whop ↔ ownership NFT
- Call-to-action commercial packs **avant** smoke PayBox + preuve delivery
