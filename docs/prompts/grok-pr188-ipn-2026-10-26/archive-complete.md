Lire le Markdown complet de cette page par l’API GitBook, le sauver sous `archive-gitbook.md`, puis exécuter :

````python
import base64, hashlib, pathlib, re, zipfile
markdown = pathlib.Path('archive-gitbook.md').read_text()

raw = base64.b64decode(''.join(block.split()), validate=True)
assert len(raw) == 78536
assert hashlib.sha256(raw).hexdigest() == 'ffc380f6635bc504fa2165c00c842a68fee5b63d5c10bec32d41ca24033ac60d'
target = pathlib.Path('xartists-pr188-resolution.zip')
target.write_bytes(raw)
with zipfile.ZipFile(target) as package:
    assert package.testzip() is None
    package.extractall('xartists-pr188-transfer')
````
