# LIA Control Room — Explore the Intelligence

**Understand the signals. Stay in control.**

The LIA Control Room is the intelligence overview inside xArtists. It is designed for touch-first mobile navigation and an optional immersive 3D experience.

## Explore the three intelligence modules

* **Pulse** — discover activity and ecosystem intelligence.
* **Yield** — explore analytical market information; no return is guaranteed.
* **Sentinel** — review monitoring and risk-oriented signals.

On mobile, select a module card to open its details. Choose **Enter immersive view** to explore the holographic 3D room on a capable device. You can return to the accessible 2D overview at any time.

## Reading the LIA status

* **Paper / shadow:** simulated or observational intelligence, not live orders.
* **Execution disabled:** LIA is not authorized to trade.
* **Signal timestamp and freshness:** use the displayed observation time and stale/available status. Missing data must never be represented as a fresh signal.
* **Unavailable:** if a feed cannot be loaded, the interface should clearly explain that no current signal is available.

## Your wallet and digital ownership

Your connected MultiversX wallet is separate from any operational wallet. Signing a transaction remains an explicit user action. NFT access depends on successful issuance and on-chain verification.
