# Vision xArtists · LIA (Vellum) — north star

> Nous construisons une dApp **double marketplace** sur MultiversX :  
> **Art / RWA / NFT** d’un côté · **Agents IA (clones LIA)** de l’autre —  
> pilotés par une IA décisionnelle dont la **mémoire opérationnelle** est la chaîne.

---

## 1. Qui est LIA

| Rôle | Description |
|------|-------------|
| **IA décisionnelle** | Modes DEFENSE · COMPOUND · MICRO_ARB · MOMENTUM · MEAN_REV · YIELD · SOCIAL_WATCH · ADVISOR |
| **Trading autonome** | Stratégies **complémentaires et/ou parallèles** (sleeves pyramides, paper → micro live) |
| **Gardienne treasury** | Split fees / tips / PnL selon `TREASURY_POLICY` · Mission · Reserve · Ops |
| **Mémoire** | Explorer + events SC + JSON publiés (`lia_v6_status`, board, kill_state) = audit trail |
| **Exécution** | Vellum workflows · wallet **LIA ops** (jamais le Connect user) |

LIA **n’est pas** un fonds ouvert au public : c’est le moteur de protocole + performance **auditable**.  
Les clients n’achètent pas “des parts de LIA” : ils achètent des **produits** (NFT art, packs agents).

## 2. Les deux marketplaces (différenciation)

### A — Marketplace **Arts · RWA · NFT**

| Parcours | Contenu |
|----------|---------|
| Studio | Mint guidé · IPFS Pinata (proxy) · phygital |
| Galerie | Collections xArtists |
| Market | List / Buy / Bid on-chain (après deploy SC) |
| RWA | Escrow bridge **pre-mainnet** · attestation |
| Rewards | **1 TRO max** / œuvre physique réelle (règle produit) |

**Valeur** : culture + ownership on-chain + fees → treasury fondation.

### B — Marketplace **Agents IA**

| Couche | Ce que c’est | Ce que ce n’est pas |
|--------|----------------|---------------------|
| **Packs LIA sub-agents** | NFT limité · 5–25 € · stake/slot · revenu passif **selon règles pack** | GreenSmoke forecast agents |
| **3 packs IA** | Profils distincts (ex. Momentum / Yield / Micro-arb) · **prix proposé par LIA** dans les bornes | Même agent GSN leaderboard |
| **Stake NFT agent** | Droit d’usage / partage de perf **contractuel on-chain** quand SC live | Promesse de rendement garanti |
| **BTC (et autres)** | Adresse ops multi-chain pour **visibilité / future % revenue share** | Live staking BTC on-chain MVX aujourd’hui |

**Vellum** : LIA peut **provisionner** un sous-agent depuis un prompt utilisateur → intent → list `agents_marketplace` une fois déployé.
