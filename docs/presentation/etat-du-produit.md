## Pourquoi les originaux Drive ne sont-ils pas des NFT ?

Une image dans Drive est un fichier source privé. Le parcours prévu est : **œuvre choisie et droits déclarés → copie sur stockage privé xArtists + SHA-256 → sauvegarde indépendante → publication consentie sur IPFS (CID contrôlé) → métadonnées vérifiables → mint signé dans le wallet de l'artiste → NFT vérifié sur MultiversX**. Le serveur conserve les fichiers et les preuves ; le NFT lui-même reste enregistré sur la blockchain.

L'inventaire historique de **291 PNG et 4 MP4** n'établit ni les droits de redistribution, ni des CIDs, ni des NFT mintés. [Guide complet Drive et sculpture](creer-vendre-nft-ipfs-drive.md).
