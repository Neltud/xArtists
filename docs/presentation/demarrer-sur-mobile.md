# Démarrer : web, mobile et xPortal

xArtists s’utilise comme une application web. On peut commencer par une visite dans son navigateur, puis connecter son propre portefeuille pour les fonctions qui le demandent. La [page de disponibilité](etat-du-produit.md) distingue la version de découverte et l’adresse GitHub Pages.

### Commencer sans portefeuille

Ouvrir la version de découverte, choisir sa langue et entrer dans le musée ou l’explorateur de modules. Aucun achat n’est nécessaire pour commencer la visite publique.

Le guide intégré et la page d’accès à la dapp regroupent les options de consultation, d’installation et de partage. Le lien ou le QR de partage ouvre la dapp ; il ne remplace pas le QR d’une session WalletConnect.

### Utiliser xArtists sur son appareil

{% tabs %}
{% tab title="Ordinateur" %}
Ouvrir la dapp dans son navigateur. Pour un usage régulier, l’option d’installation peut être proposée par le navigateur lorsqu’il la prend en charge. Sinon, conserver le lien dans ses favoris permet de revenir à l’application.

Pour une connexion xPortal disponible, ouvrir le bouton de connexion dans la dapp, choisir xPortal ou WalletConnect et scanner le QR de la session avec le portefeuille sur son téléphone.
{% endtab %}

{% tab title="Android" %}
Ouvrir la dapp dans un navigateur compatible. Si un bouton **Installer xArtists** est proposé, suivre la demande du navigateur. Une option d’ajout à l’écran d’accueil peut également être disponible dans son menu.

Pour connecter xPortal sur le même téléphone, utiliser l’ouverture de l’application proposée par le parcours WalletConnect. Les libellés varient selon la version du navigateur et du portefeuille.
{% endtab %}

{% tab title="iPhone ou iPad" %}
Ouvrir la dapp dans **Safari**, puis utiliser **Partager → Sur l’écran d’accueil** si cette option est disponible. L’icône donne ensuite un accès direct à l’application web.

Pour une connexion xPortal disponible sur le même appareil, suivre le lien d’ouverture du portefeuille et revenir dans la dapp après la validation de session.
{% endtab %}
{% endtabs %}

L’ajout à l’écran d’accueil est une installation d’application web. La présentation n’annonce pas de publication de xArtists sur l’App Store ou Google Play.

### Comprendre la connexion au portefeuille

{% stepper %}
{% step %}
#### Ouvrir la connexion depuis la dapp

Utiliser le bouton prévu dans l’interface, après avoir vérifié l’adresse du site consulté.
{% endstep %}

{% step %}
#### Lire la demande dans son portefeuille

Vérifier le nom du site, l’adresse et la nature de la demande. Une approbation de session, une signature de message et une transaction ont des effets différents.
{% endstep %}

{% step %}
#### Retrouver son compte dans l’application

Après connexion, vérifier que l’adresse affichée est celle du compte choisi. Consulter ses actifs ou poursuivre un parcours disponible.
{% endstep %}

{% step %}
#### Valider séparément toute action proposée

Une opération demandant une signature doit être examinée dans le portefeuille. L’ouverture de la dapp n’est pas une autorisation générale de paiement.
{% endstep %}
{% endstepper %}

### Si une connexion ou une installation n’est pas proposée

L’interface et le navigateur peuvent proposer des options différentes selon l’appareil. Reprendre la navigation web reste possible sans installer l’application. Si une session de connexion expire, la fermer et recommencer depuis la dapp plutôt que de réutiliser un ancien QR.

La compatibilité de l’interface avec xPortal et une présence dans son catalogue sont deux sujets différents. Le référencement xPortal et la validation finale sur appareils réels restent indiqués dans [État du produit](etat-du-produit.md).

### En cas de perte de connexion

Les informations de compte, les données blockchain et les opérations signées nécessitent une connexion réseau. Le mode hors ligne peut donner accès à certains éléments déjà chargés ; il ne doit pas être utilisé pour interpréter un solde, un statut ou un prix comme actuel.

Référence complémentaire : [documentation MultiversX sur les connexions et transactions de dapp](https://docs.multiversx.com/sdk-and-tools/sdk-dapp/).
