# LIA Control Room — Public guide

## AI intelligence you can inspect, without connecting a wallet

Visit **[LIA Control Room](https://neltud.github.io/xArtists/intelligence/lia)**. The first view is designed to show published signals, their source timestamps, and clearly labelled paper-mode performance. Use **Refresh signals** to check for a newly published snapshot. Refreshing your browser does not refresh the underlying data provider.

### What you can see

- **Reported strategy** — the latest published agent strategy, not a trade instruction.
- **Shadow performance** — simulated P&L; not financial returns or realized profit.
- **Wallet snapshot** — a previously published on-chain balance; not necessarily the current balance.
- **Data freshness** — separate timestamps for the public aggregator and the Vellum/hub mirror. If a publisher is stale or unavailable, the page says so.
- **Pulse, Yield and Sentinel** — links to read the module concepts and access conditions.

### Two views, one clear distinction

The default 2D dashboard works without WebGL, including on desktop. **Enter immersive view (3D)** is an optional visual experience. **Advanced intelligence & diagnostics** reveals additional market tickers, asset data, technical telemetry and paper intent logs for interested visitors. Those tools are not proof of automated on-chain execution.

**Current execution status:** LIA uses paper/shadow mode; live trading is disabled. All on-chain actions require independent checks and user authorization. This page does not initiate transactions or require a connected wallet.
