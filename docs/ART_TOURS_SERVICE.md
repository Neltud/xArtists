# Service Tours artistiques xArtists

**Ce n’est pas un pack agent IA.**

## Offre

Service de **tours artistiques** :

- Visites guidées / semi-guidées d’expositions
- Itinéraires galeries & musées (villes partenaires)
- Lien phygital : œuvres / éditions xArtists quand disponibles
- Agenda culturel + signaux soft (pas de trading auto)

## Hors scope v1

- Réservation hôtel / vol
- Custodie de fonds voyage
- Pack NFT « agent de voyage »

## UI

- Route : `/#/tours` (alias historique `/#/agents/voyage` → redirection soft)
- Data : `data/art_tours.json`

## Lien Vellum

LIA peut **informer** (agenda, villes, expos) via intent « tour / expo / galerie ».  
Paiement éventuel : fiat on-ramp ou Lightning **ops** — pas confondre avec packs Pulse/Yield/Sentinel.
