### Console / external-data warnings

1. `frame-ancestors` delivered by HTML CSP meta is ignored by the browser; should be in an HTTP CSP header at an appropriate host/CDN layer, not claimed as protection in meta.
2. HTTP Akash catalogue URL is blocked by the current restrictive `connect-src` CSP. Use an audited HTTPS endpoint or a same-origin proxy, with explicit TLS and CORS checks.
3. Frankfurter currency rate fetch produced CORS errors on LIA and Command Center; the app needs a signed, cached data source or a labelled unavailable fallback.
4. Mobile Command Center CoinGecko requests produced CORS errors; should not label blocked data as live.
5. Consumer mobile readability and WebGL performance still need manual device checks after the automated captures.

### Checkout/product audit

- React `CheckoutModal.tsx`: crypto/fiat rail and provider selection can still mutate while busy or during terms approval in the old source. Lock choices until completion and prevent accidental modal dismissal.
- `PackCheckout.tsx` preview calls `markPackOwned`, but `nftPacks.ts` explicitly protects this DEV-only cache; production access is derived from on-chain NFTs, not localStorage. Remove the misleading preview cache write rather than falsely reporting a production entitlement exploit.
- **Price discrepancy:** historical references to 10/5/2.5 EGLD contrast with newer 33/22.5/15 catalog anchors. Actual smart contract `getPackPrice`, quote binding and fiat conversion must be independently compared before taking payments; static displayed EGLD is not an authoritative quote.
- Trade lock and real mint are separate domains. Publishing a React interface is not approval for live orders, stablecoin movement or self-directed LIA transactions.

## P0 release gates before financial live

- Operator-controlled real Sentinel €50 payment with buyer wallet, unique order, bank response, authenticated RSA IPN, same-buyer entitlement and independent mint TxHash.
- Replay/duplicate IPN, concurrent order, payout and refund/revoke/reconciliation evidence.
- No dry-run or disabled mint dispatcher if a checkout advertises immediate NFT delivery.
- Real database recovery, PSP incident pause and kill switch, secrets redacted and safe idempotent retries.
- Source of authoritative on-chain pack pricing and rights, legal conditions, fees, returns and artist permissions.
- LIA Ops no-sign freeze, risk Guardian, isolation/caps, and exchange-watch status checked with human approver. Do not re-enable LIA Ops tonight from the website release.
