# Sprint 4 — Soft launch

**Statut** : PRÊT (après Sprint 3)  
**Objectif** : cohorte limitée + plafonds + support + 7 jours de surveillance + Go/No-Go formel.

## Checklist

- [ ] Cohorte limitée (liste blanche ou invite)
- [ ] Plafonds de supply et par wallet
- [ ] Support client actif (canal + SLA)
- [ ] Surveillance 7 jours (incidents, erreurs, remboursements)
- [ ] Audit / revue indépendante des composants critiques
- [ ] Revue Go / No-Go avec métriques :
  - incidents
  - remboursements
  - écarts prix
  - taux d’erreur

## Critère de sortie

Décision Go/No-Go documentée + soft launch validé + preuve de stabilité.

## Périmètre Go recommandé

Genesis packs + galerie + LIA Hub paper.  
LIA live trading et paiement large public hors scope jusqu’à validation explicite.
