# ⚠️ Legacy Source Directory

This `src/` directory at the repository root is **legacy code** and is no longer the active application.

The active frontend is located in [`apps/frontend/src/`](../apps/frontend/src/).

This directory is retained for reference and may contain useful service stubs (`services/mvx.ts`, `services/price.ts`) that can be migrated to the active app or to `packages/core`.

**Do not build or deploy from this directory.**
